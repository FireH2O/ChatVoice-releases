# ChatVoice releases

**ChatVoice** reads your VIBIE live chat aloud in Thai. It is a small, free Windows app made for a few friends.

## Download
**Download page: https://fireh2o.github.io/ChatVoice-releases/**

Get the newest **`ChatVoice-Setup-X.Y.Z.exe`** from [Releases](https://github.com/FireH2O/ChatVoice-releases/releases/latest) and run it.

- No admin needed: it installs for your user only.
- Windows SmartScreen warns because the installer isn't signed with a certificate: **More info → Run anyway**.
- Needs Chrome or Edge and WebView2, which is part of Windows 11 and up-to-date Windows 10.
- Once installed, ChatVoice **updates itself**. It downloads new versions in the background, never while it is reading a live, and installs them when you close it. You can turn this off in Settings > Updates.

## Good to know
- ChatVoice is not made by or affiliated with VIBIE. It reads the public viewer page of your live.
- The Microsoft and Google voices are free online services used unofficially. They can stop working without notice.
- Each release has `latest.json`, a signed description of the installer. ChatVoice checks it before installing anything.

This repo only holds the releases. The source code is private.
